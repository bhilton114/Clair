# Security Policy

Project Clair's active V4 implementation includes private development material that is intentionally not mirrored into this public repository.

## Do Not Publish

Please do not disclose publicly:

- credentials, API keys, tokens, passwords, or environment secrets
- private server configuration
- internal security controls or bypass techniques
- unpublished governance logic
- exact private thresholds, guard values, or recovery conditions
- private benchmark fixtures or evaluator answers
- proprietary continuity, memory, routing, or authority mechanisms
- personal or user-specific data

## Reporting

If you believe you have found a security issue in material already published here, use a private contact method associated with the repository owner rather than opening a public issue.

## Public Repository Scope

This repository is intended to expose:

- high-level architecture principles
- public research direction
- verified milestone summaries
- non-sensitive examples and documentation

The absence of implementation detail is deliberate.

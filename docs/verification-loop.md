# Verification and Governance

Clair's verification research focuses on preventing unsupported candidate material from being treated as established fact merely because it was produced fluently.

## Public Principles

- candidate answers and verified claims are different states
- evidence should be inspectable
- uncertainty should influence acceptance
- conflicting evidence should remain visible to the system
- tools and models do not self-certify their own outputs
- final acceptance is a separate responsibility

## Current Research Direction

Verification is being evaluated across document reasoning, tool use, local model assistance, and long-lived memory behavior.

## Public Scope

Exact verification rules, scoring behavior, guard thresholds, fallback logic, and private test cases are intentionally withheld.

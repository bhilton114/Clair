## Rules for interpreting stages

- The **Clair** repository is the canonical public entry point.
- Historical repositories are preserved for provenance, not treated as competing current products.
- Different test totals come from different revisions and suites and cannot be added together.
- Public documentation must distinguish architectural intent, developer-reported tests, and independently reproduced results.
- Do not interpret a public documentation repository as an open-source release of private V4 internals.

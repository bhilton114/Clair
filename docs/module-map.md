# Public Capability Map

Clair V4 is organized into bounded capability areas rather than one monolithic inference process.

Publicly described areas include:

- intake and perception
- routing
- reasoning
- calibration
- verification
- working and durable memory
- planning and simulation
- tool/resource use
- response acceptance
- reflection

The full internal module map, ownership seams, file structure, and execution contracts are intentionally withheld from the public repository.
